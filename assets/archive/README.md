# Archived brand assets

This directory is reserved for superseded Shiroe artwork and historical brand material.

## Active snapshots

The current approved repository snapshots live at:

- `assets/shiroe-character-snapshot.png`
- `assets/shiroe-character-snapshot-motion.svg`

## Archive policy

- Move replaced artwork here instead of deleting it when historical comparison is useful.
- Do not reference archived artwork from active README, documentation, package, or release surfaces.
- Legacy Zeref artwork is historical only and must not appear on active Shiroe surfaces.
- Raw generation files, third-party references, font files, and private production material do not belong in the public repository.

At the time this archive structure was introduced, the live `dev` branch contained no tracked snapshot asset to relocate. This file records the retirement policy without claiming that an existing live file was moved.
